Panduan Perakitan Assemblr Edu

Langkah menyusun Ruang Karya 3D pada Assemblr Studio / App

1 Langkah Pembuatan Proyek Baru

  1. Buka aplikasi Assemblr Edu (iOS/Android) atau akses Assemblr Studio Web di browser.
  2. Klik tombol "+" (Create New Project) dan beri nama STEM Makerspace Impian.
  3. Atur status visibilitas proyek menjadi PUBLIC agar dapat diakses publik.

2 Pencarian Aset di 3D Library Assemblr

Kata Kunci Aset 3D (Search Terms):

• Meja Eksperimen: Lab Table, Science Desk, Microscope, Beaker, Flask
• Kolaborasi: Office Desk, Computer, Monitor, Whiteboard, Chair
• Penyimpanan: Wooden Cabinet, Storage Shelf, Storage Box
• Portabel: Utility Cart, Wooden Box, Tools Set

3 Menambahkan Pin Anotasi Interaktif (i)

Gunakan tombol Annotation (T / +) pada Assemblr Edu untuk menempatkan 3 Pin Utama:
Pin 1: Meja Eksperimen | Pin 2: Area Kolaborasi | Pin 3: Lemari Penyimpanan.

Tips Penilaian: Setelah proyek Assemblr Edu selesai, klik Publish / Share, unduh QR Code Proyek, lalu tempelkan pada Lembar Laporan Aksi Eksperimen Formula 5 Anda!
